How the value is worked out

Implied value = TVL × 0.30 × growth × maturity × chain × category. Every figure comes from the snapshot itself: the protocol's TVL, its seven-day TVL change, and how long it has run with no token. No name is hardcoded anywhere — the same formula ranks all 758 protocols, and the board keeps the ones that record no token.

  • Growth: the 7-day change, clamped to −50…+150%. A rise is rewarded at 0.6 per point; a fall is penalised at 1.2 per point.
  • Maturity: 0.70 for a protocol listed yesterday, rising linearly to 1.00 at three years. A protocol that has run for years with no token has a deeper base for a token to land on.
  • Chain: the best chain it runs on, up to 1.10 for Ethereum. A token needs somewhere liquid to trade.
  • Category: what a token can claim of the TVL — a direct fee (lending, exchanges, real-world assets) scores above a thin slice (curators and allocators).

“Records no token” is a statement about DefiLlama's record, never a claim that the protocol has no token. A protocol on the watchlist may still have a token its record does not carry. The watchlist is a floor, never a ceiling: the board also ranks 158 protocols below it. This radar does not predict whether or when a token is issued, and an implied value is this entry's own claim.
